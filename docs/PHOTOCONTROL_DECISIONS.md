# Решения владельца по развилкам §11 плана фотоконтроля

Дата: 2026-08-06. Владелец ответил на все 14 развилок `PHOTOCONTROL_INTEGRATION_PLAN.md` §11.
Все решения совпали с рекомендациями плана. Этот файл — протокол, чтобы решения
не жили только в переписке; при расхождении с планом верен этот файл.

| № | Развилка | Решение |
|---|---|---|
| 1 | Что сдаём первым | **Макет PDF** («до печати», этап 2). Фотопуть — после. |
| 2 | Провайдер OCR (этап 4) | **Azure Document Intelligence** с обязательным пилотом на 200-300 реальных фото; due-diligence (оплата из UZ, регион, DPA) стартует в нулевой день. Запасной путь — self-host PP-OCRv6. |
| 3 | Хранение снимков | **Оригиналы 30 дней** в приватном бакете с работающей джобой удаления; кропы-доказательства — бессрочно вместе с вердиктом; экран явного согласия до первой загрузки. |
| 4 | Габариты упаковки | **Из MediaBox на макетном пути с этапа 2**; на фотопути — честный отказ до этапа 6, потом разовый ввод пользователем на SKU. |
| 5 | Источник правды правил | **YAML в git** (inspectorx-vision), ревью через PR; база — односторонняя выгрузка на этапе 6. |
| 6 | has_gold | **Метрика на этапах 1-5** (четвёртый список отчёта), **гейт с этапа 6**. |
| 7 | Подпись человека | **Только критичные находки, с этапа 5**, SLA один рабочий день; до подписи вердикт «предварительный». |
| 8 | Единица тарификации | **Прогон** (1 проверка = 1 единица квоты), потолки: 3 ревизии досъёмки, 2 ретрая. |
| 9 | Кто размечает эталоны | **Фикстуры своими силами** (разработчик пишет, юрист вычитывает) **плюс покупные/снятые точечно фото-эталоны**. Вопрос ADR-0001 «платим ли экспертам» закрыт: да, точечно — за фото-эталоны и вычитку. |
| 10 | Рынки UZ и ЕАЭС | **Оба**; `markets` на требованиях + механизм превосходства норм — на этапе 6. |
| 11 | Число уверенности в отчёте | **Не показывать числом.** Три класса («машина прочитала» / «нужен человек» / «не проверяется») плюс `decided_by` словами. |
| 12 | Пейволл на этапах 2-5 | **Раздел бесплатен подписчикам, квота 5 проверок за 30 дней**; демо-клиентам лимит поднимается вручную. Размытый муляж на результат не ставим. |
| 13 | Заявки на анонс | **Список для закрытой платной беты после этапа 2** — под макетный сценарий, не под фотографии. |
| 14 | Занятость исполнителя | **Полная на этапах 0-2.** Календарь — 19 недель; при переходе на «пополам» после этапа 2 — пересчитать. |
