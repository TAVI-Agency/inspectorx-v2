# docs/legal — юридические черновики

## Что это

Папка с **черновиками** публичных юридических документов InspectorX. Оба файла —
заготовки **для вычитки юристом**, а не готовые к публикации тексты:

| Файл | Что это | Куда пойдёт после вычитки |
|---|---|---|
| `offer-draft.md` | Публичная оферта на оказание услуг | https://inspectorx.uz/offer |
| `privacy-draft.md` | Политика конфиденциальности | https://inspectorx.uz/privacy |

Сейчас в подвале сайта на месте этих ссылок стоит заглушка «Оферта · Политика
конфиденциальности — скоро» (`src/i18n/ru.ts`), см. блок D в `docs/LAUNCH_CHECKLIST.md`:
юридический минимум — единственный настоящий блокер приёма денег.

**Правила работы с этими файлами**

1. Шапка «ЧЕРНОВИК — требует вычитки юристом; не публиковать» снимается только юристом.
2. Всё неизвестное — в угловых скобках `⟨…⟩`. Не подставлять значения «по смыслу».
3. Норму, которую не удалось подтвердить первоисточником, помечать
   `⟨уточнить у юриста: …⟩`, а не изобретать номер статьи.
4. Ничего не обещать сверх того, что в продукте уже есть. Сверяться с
   `docs/LAUNCH_CHECKLIST.md` (что реально работает) и `docs/PHOTOCONTROL_DECISIONS.md`
   (принятые решения по фотоконтролю).
5. Слов «проверено юристом», «подпись юриста», «юрист-верификатор» в публичных текстах
   быть не должно — правило из `deck/README.md`: юрист каждое требование не проверяет.

Дата подготовки черновиков: **11.09.2026**. Нормы проверены на эту дату.

## Продуктовые пробелы, обнаруженные при подготовке черновиков

Не юридические вопросы — задачи на код/операционку. Вынесены сюда, чтобы не потерялись:

1. **Экрана явного согласия перед первой загрузкой в фотоконтроль в интерфейсе нет.**
   Решение № 3 `PHOTOCONTROL_DECISIONS.md` его предписывает, п. 7.9 оферты и п. 5.1
   политики на него ссылаются. Нужно добавить до публикации документов.
2. **Поставщик распознавания для фотоконтроля не зафиксирован** (`photo_model_calls.provider`
   — свободное поле). Пока он не определён, п. 6.4 политики честно назвать нельзя.
3. **Sentry и веб-аналитика не подключены** — строки в п. 6.2 политики условные.
   При подключении политику надо обновить в тот же день.
4. **Реквизиты компании пустые** в `src/config.ts` (`COMPANY.legalName/inn/address`) —
   те же значения нужны и в документах, и на странице контактов (её роута тоже нет).
5. **Цена тарифа не утверждена** — публиковать оферту с неутверждённой ценой нельзя.
