## Решения фаундера (North Star)

**13.07 (луповый формат):**
1. UZ-ветка гейта — да.
2. Агентный ресёрч пустых секций из официальных источников — да (публикация только через гейт).
3. Сервисные отчёты — в прод через гейт.
4. Цель: **≥3 требования на секцию товара / этап услуги**, либо явный статус «норм нет,
   проверено». Верификация каждой итерации — по проду (measure_prod.py), «глазами цифры»,
   не только тестами. Процесс итерационный, не единичный проход.

**16.07 (UZ-first, спека):**
1. Боль: неполнота + потери по пути + непроверенность.
2. Источник: гибрид — Sonnet-агенты добивают пустые секции и очередь; ручной deep research
   только для discovery новых товаров/услуг.
3. Автономия: авто-публикация через гейт + агент-аудитор на второй модели; человеку — только конфликты.
4. Узбекский — канонический язык данных, русский — производный; **юрцитаты моделью не
   переводятся никогда** (только дословные выдержки с официальных страниц).
5. Подход: эволюция конвейера + накопление библиотеки узбекских оригиналов (verbatim_uz).

**Правила процесса (не нарушать):** в БД мимо гейта — никогда; дедуп-ключ
`lexuz:{doc_id}/{ref}` канонический; словари закрытые (правка руками); ошибка item
не валит прогон (→ review с причиной); коммиты от TAVI-Agency.
