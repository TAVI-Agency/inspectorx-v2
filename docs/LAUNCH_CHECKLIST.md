## Историческая часть (решения 11.07.2026, не редактируется)

**Стратегия двух треков.** Трек 1 — запустить текущий продукт как витрину и сборщик
заявок, потом заморозка (только контент). Трек 2 — чистый проект по TARGET_FORMAT,
2–4 недели, затем переключение домена. *По факту трек 1 пропущен, живёт трек 2.*

**Реальность по оплате.** Click требует юрлицо/ИП + договор + ключи — это дни.
На запуске: пейволл с ручной активацией, заявка → связались → админ ставит флаг.
Параллельно — реактивация ИП, потом Click SHOP API на готовую страницу тарифа.

**Модель пейволла.** Бесплатно — поиск, страница товара, заголовки требований, первый
уровень. По подписке — детали карточек, уведомления, вопросы, услуги.
*Реализовано строже плана: граница не на фронте, а в RLS.*

**Правило заморозки** (действует): в этот код после запуска добавляется только контент,
новые фичи — через TARGET_FORMAT.md.
