## Стратегия: два трека (принято 11.07.2026)

- **Трек 1 (этот чек-лист):** завтра запускаем текущий продукт как витрину и сборщик заявок.
  После запуска — **ЗАМОРОЗКА**: в этот код добавляется только контент. Ни одной новой фичи.
  Любая идея «а давай ещё сюда...» → записывается в TARGET_FORMAT.md, а не кодится здесь.
- **Трек 2 (с понедельника):** чистый проект по TARGET_FORMAT.md — новая схема данных,
  нормальный код, услуги, 3 языка. Срок: 2-4 недели. Готов → переключаем домен,
  подписчики и заявки переезжают. Витрина трека 1 до этого момента живёт и собирает лиды.

## Реальность по оплате (принято 11.07.2026)

- Click-мерчант требует действующее юрлицо/ИП + договор + выдачу ключей → **это дни, не часы**.
- **На запуске:** пейволл с ручной активацией. Кнопка «Оформить подписку» → страница тарифа →
  заявка (имя, телефон/Telegram, компания) → мы связываемся → активируем вручную
  (админ ставит флаг подписки). Оплата: перевод/счёт — легально после реактивации ИП.
- **Параллельно (не блокирует запуск):** сегодня-завтра начать реактивацию ИП →
  подать заявку на business.click.uz → после получения ключей прикрутить Click SHOP API
  к уже готовой странице тарифа.

## Модель пейволла (принято 11.07.2026)

- **Бесплатно:** поиск, страница товара, список требований (заголовки), первый уровень контента.
- **По подписке:** детали карточек (выдержка из закона, рекомендации, санкции, FAQ),
  уведомления, вопросы, услуги (какие успеем).
- Реализация на завтра: гейт на фронте (блюр + CTA на детальных блоках) + флаг `is_subscribed`
  в profiles. ⚠️ Серверное закрытие данных через RLS — доделать в первую неделю после запуска
  (фронт-гейт обходится, для первых дней приемлемо, для масштаба — нет).
- ❗ РЕШИТЬ СЕГОДНЯ С ДЯДЕЙ: цена и название тарифа (нужна цифра на лендинг, даже при ручной
  оплате). Рекомендация: один тариф «Ранний доступ» ~99 000–149 000 сум/мес, поднять позже.
